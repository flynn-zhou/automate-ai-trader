## 读数层（第 5 步之后加的）

    python tools/show_kbar.py --at "2026-11-07 23:45"   # → 【恐慌盘】
    python tools/show_kbar.py --at "2026-11-08 05:15"   # → 【插针后稳住】，稳的是 04:45
    python tools/probe_kbar_shape.py                    # 独立重算 17,654 根 + 分布

`show_kbar` 的**第一段就是判定**，客观值退到下面当证据。五个状态词
（外加一个「无」）：`恐慌盘` / `插针收回` / `插针` / `插针后稳住` / `针后远离`，
都不成立时是 `无`。

判定**落在表 5 `kbar_shape`**（用户 2026-11-08：「所有演化结论字段或者描述
都要入 db 库！这个落盘数据库是必须的」）。17,654 行，一根一行，每行带
`params_hash` 指纹。

阈值全是临时值（D-21，现在八个）。**改 `shape.py` 顶部常量之后必须重算表 5**：

    python tools/backfill_kbar_shape.py --rebuild

不重跑的话表里会混着两套口径 —— `tools/check_kbar_pipeline.py` 会红，
`show_kbar` 也会在标题打「旧口径」。（v1 时代那句「不用重建任何表」已作废。）

两个已经查明的判据坑，别再改回去（详见实现记录 §三十九）：

1. **恐慌盘不要求本根是插针。** `close_pos = 0` 时下影恒为 0，收在最低点的大阴线
   永远不是针 ⇒ 「以插针为前提」等于把它最典型的形态排除掉。
   方向由 `panic_side` 给：有影线听影线的，没有影线才看收位。
2. **“针”有两种形态**：长影线 `wick` / 已确认的局部极值 `swing`。
   `swing` 只许用「到今天为止」的数据判，看之后就是偷未来。
   但极值针只当「稳住/远离」的参照，本根不打 `插针` 标签
   （否则下跌趋势里每根新低都是插针，全库 33.1%）。

**不要**因为某根判错就去给它开特例。用户原话：「这两个点我只是举例，
不仅仅只此 2 点哦」—— 要改就改阈值，让规则自己覆盖它。

## 佐证层（表 6，2026-11-08 加的）

用户的要求：判断对不对，**用后面的 K 线回头验**。这是全项目唯一允许看未来的地方。

    python tools/backfill_kbar_verify.py                # 回填表 6（35,308 行）
    python tools/probe_kbar_verify.py                   # 命中率 + 基准 + 提升 + z + 分层
    python tools/show_kbar.py --at "2026-11-08 05:15"   # 带【佐证】段
    python tools/show_kbar_batch.py --preset anchor6    # 多根结论字段并排（验收用）
    python tools/check_kbar_pipeline.py                 # §7.7 校验表 6

N = 1（主）+ 3（看延续性），容差 **0**（不是 after_pin 那个 20，别扩散）。
裁决四值：`佐证成立` / `被推翻` / `无法判定`（表尾没凑满 = 没验，不是成立）/
`无预言`。

**红线：`shape.py` 绝不许 import `verify`。** 表 5 是输入，表 6 是旁注，永不回写。
§7.7 有源码扫描检查这一条。

**三条硬规矩**（详见实现记录 §四十）：

1. **命中率单独看没有意义。** N=1 时「随便一根本根低点后面不被破」本来就有 53.1%。
   必须和**同口径基准**并排，还要看 z。
2. **基准必须与预言用同一个参照点**，否则是苹果比橘子（这个坑踩过两次）。
3. **参数分层。** 「稳住/远离」的定义里就含「离针多远」，不分层就是把
   「它离得近」当成「它判得准」（「远离」+19.6 → 分层后只剩 +3.6）。

佐证层翻出三件**要用户定**的事（D-22，我没动判据）：
「恐慌盘」一个词装了两个相反行情（有无影线走向相反，两边 z>4）；
「稳住」在**向上方向是反的**（上针每个距离桶都是负提升）；
「远后远离」的高命中率是距离带来的。
