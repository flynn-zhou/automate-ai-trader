# S5 · 现实跟随出场（区间演化 + K线演化判风向）

> 定位：**设计稿，未实现**。这一层决定盈亏 —— 前面两条名义线（止损 = d_max、
> 止盈 = 4R）都是「挂上去但多半到不了」的线，真正把仓位平掉的是这里。
>
> 用户口径（原话，不要再改）：
>
> > 「止盈不是固定的，可以先定一个很远的止盈，但是我想要的是现实跟随，
> >   根据我们的区间演化+K线演化，判断风向！且任何一根5m的持仓顺向涨跌幅
> >   达到500U，都要立即止盈，因为很难得！……我们不是长线，遇到这种惊喜K线必须走」
>
> > 「K线演化和区间演化就用原先我们已经上线的周期」（区间 = 1h；K线 = 5m/15m）

## 0 · 三条线的分工（已经定下来，这里只复述）

| 线 | 值 | 性质 | 到不了正常吗 |
|---|---|---|---|
| 初始止损 | `d_max = (1/lev − mmr)×100/safety` = 1.6182% | **硬兜底**，撞到必亏 R | 撞到就是亏，不希望撞 |
| 4R 止盈 | `4 × d_max` = 6.4727% | **名义天花板** | ✅ 正常，多数到不了 |

止损距离里已经扣掉了往返成本（`d_max − cost`），所以「止损 + 成本 = d_max = R」。

## 1 · 三个实测事实（它们决定了设计长什么样）

### 事实 1 · 4R 在日内基本到不了

持仓中位数 **7 根 5m（1.8 小时）**，最长 23 根（5.8 小时），9 笔里 0 笔超过 24 小时
（§25.3 实测）。而 4R = **6.47%** —— 1.8 小时走 6.47% 是极端事件。

⚠ **这个中位数是在「形态止损 85~164 点」下测的。** 现在止损改成 d_max
（约 1200 点），持仓会**变长**，所以「到不了 4R」的程度会缓和一些，
但 6.47% 仍然是极端量级。**不要拿旧的 7 根当中位数用。**

→ 结论：止盈必须由现实给，不能是固定线。这与用户口径一致。

### 事实 2 · 入场价周围 0.03%~0.5% 内挤着一堆线，**前后都有**

11 条真实计划（8 万 / 6.4 万两个价位段），相对持仓方向的最近线：

| | 中位 | 最小 | 最大 |
|---|---:|---:|---:|
| 有利方向前方最近线 | 0.106% | 0.007% | 0.504% |
| 不利方向后方最近线 | 0.048% | 0.000% | 0.356% |

前方最近线**轮流**是 `range_p` / `ema20` / `swing_low` / `prior_low` /
`donchian_hi` / `range_key` / `ema144` —— 没有一条是稳定的主角。
11/11 条计划**前后都有线**（所以参照物永远不缺席）。

配套：5m 平均每根碰 **1.37** 条线，**36% 的根一条都不碰**（`n_touch=0` 12,528/34,561）。

→ **结论：「价格越过某条线」不能当信号。** 越线是常态（每根 1.37 次），
不是事件。把越线当信号，等于每分钟都出场一次。

### 事实 3 · 带信息的是「越线之后怎么走」，而这件事已经被判好了

kbar 的 7 个结论词正好把这个区分编码在里面（5m 全样本 34,561 根）：

| 结论词 | 5m 根数 | 占比 | 操作含义 |
|---|---:|---:|---|
| 无·贴线 | 12,658 | 36.6% | 贴线但没刺穿 — **中性** |
| 插针后稳住 | 8,566 | 24.8% | 刺穿后站住 — **偏确认** |
| 无·真空 | 7,499 | 21.7% | 什么都不挨 — **中性 / 未兑现** |
| 插针收回 | 1,695 | 4.9% | 刺穿又收回 — **假动作** |
| 针后远离 | 1,485 | 4.3% | 刺穿后单边走开 — **真动作** |
| 恐慌盘 | 1,411 | 4.1% | 放量恐慌 — **末段** |
| 插针 | 1,247 | 3.6% | 只刺穿，尚无结论 — **待定** |

→ **风向的判据不是「线破了」，是「破了以后是 `针后远离` 还是 `插针收回`」。**

这一句是整篇设计的地基。**判据从「几何位置」换成「穿透后的行为」**，
而行为这一层，kbar 已经判完了，不需要新造。

## 2 · 设计主体：四道出场闸 + 一道棘轮

沿用现有 `_close_position` 的优先级串（止损 > 正常止盈 > 惊喜K线 > 预期失效），
新的插进这个串里，**不另起一套判定**：

| # | 闸 | 读什么 | 机制（为什么它应该影响结果） | 新阈值？ |
|---|---|---|---|---|
| 1 | **止损** | 计划价（`d_max − cost`） | 硬兜底，不参与策略争论 | 否 |
| 2 | **4R 名义止盈** | 计划价（`4 × d_max`） | 天花板，几乎不响 | 否 |
| 3 | **惊喜K线** | 单根 5m 顺向 ≥ 500 点 | 已实现（§25.4） | 否 |
| 4 | **恐慌盘顺向** | `label=恐慌盘` 且方向顺我 | 加速末端：一次性流动性释放，日内不续；与「惊喜K线必须走」同源，是它的慢速版 | 否 |
| 5 | **风向翻转** | 不利方向 `针后远离`（放量）+ 1h 反转事件 | 现实否决预期：破位后不但没收回，还单边走开 | **是（1 条）** |
| 6 | **保本棘轮**（不是出场，是移损） | 有利浮盈 ≥ 1R | 到手的 1R 不许还回去 | 否（= d_max） |

### 2.1 「保本棘轮」应该第一个做

理由不是它最聪明，是它**风险最低、收益最确定、且不需要新阈值**：

- 触发点用 **1R = d_max**（仓位本来就是按它定的），不是拍脑袋的百分比。
- 只朝有利方向移动，符合硬不变量「止损永不后退」。
- 它把「先赚 1R 再亏 R」这一类最伤的单子变成「先赚 1R 再平」。
  这类单子在窄止损年代一次都没被处理过 —— 因为那时候根本没有 1R 这回事。

### 2.2 风向翻转的两条腿，一条长一条短

**腿 A · 区间演化（1h，权威但稀疏）**

收盘越过**反向边界 R** ⇒ 反转事件 ⇒ 走。

⚠ **实测泼冷水**：11 条真实计划里，R 落在止损距离（1.6182%）**之内的是 0 条**
（最近的后方线中位只有 0.048%，但那是 ema20 / soft 这类，不是 R）。
1h 的 R 是一条**远线**。

→ 所以腿 A 是**安全带**，不是主力。它防的是「区间家族整个翻转」这种极端情况，
不是常规出场。**不要指望它贡献出场次数。**

**腿 B · K线演化（5m，密集，主力）**

在**我们有利的方向**上：

| 观察 | 判定 | 动作 |
|---|---|---|
| `针后远离` + 放量 | 破位被承认，现实顺风 | **持有**（甚至可以移损到该线） |
| `插针收回` | 破位被否决，假动作 | **逆风 +1** |
| `插针后稳住` | 刺穿后站住，未定 | 中性 |
| `无·贴线` / `无·真空` | 什么也没发生 | 中性 |
| `插针` | 只刺穿，尚无结论 | 中性（等下一根） |

**逆风累计 2 次 → 出场。**

★ 方向从这里取：`kbar_reaction.side`（从上方还是下方来碰，填充率 100%），
**不用** `kbar_shape.side`（填充率只有 11.8%，拿它会大面积拿到 None）。

### 2.3 实测校准 —— 这一段推翻了我自己上面的推荐

**量了「任意起点后 20 根内出现 `插针收回` 的基准概率」**（全样本 34,541 个起点）：

| 门槛 | 基准触发率 |
|---|---:|
| ≥1 次 | **56.8%** |
| ≥2 次 | **26.8%** |
| ≥3 次 | 10.0% |

三个结论，按严重程度排：

#### ① `逆风累计 1 次` 是个抛硬币，直接否掉

56.8% 的任意窗口都会撞上至少一次。用 N=1 等于「过半仓位在前 20 根内被平掉」，
而且与被平掉的那笔是否真的走坏了**无关**。

#### ② `插针收回` / `针后远离` 在无条件分布上基本是对半

    插针收回  1,695 根
    针后远离  1,485 根

也就是说，**「破位后收回」和「破位后走开」在 5m 上大致五五开**。
单看这个标签，信息量接近于零 —— 它只有在**条件化**（已经持仓 / 区间方向一致 /
量能配合）之后才可能带方向。所以按 §九 的三关，**它现在还不够格当判据**，
先用它当「提示」，同时把条件化之后的 lift 量与基准比（26.8% 这个数就是基准）。

> ⚠ 这正是本项目最贵的一条教训：命中率单独看毫无意义，必须配同口径基准。
> 26.8% 是分母，不是 0。

#### ③ 方向上有一个真实的、必须写下来的不对称

| 标签 | `from_below`（向上破位） | `from_above`（向下破位） |
|---|---:|---:|
| 插针收回 | 1,832 | 1,776 |
| **针后远离** | **1,371** | **509** |

**向上破位后单边走开 1,371 次，向下破位后单边走开只有 509 次（73% : 27%）。**
同期真实计划里 7 条做空、4 条做多 —— 也就是**多数仓位押在「确认信号更弱」的那一侧**。

这不是「做空不能做」（形态有它自己的边际），而是：**风向判据的可靠性按方向不对称**，
拿同一个门槛套两个方向，等于把 27% 那一侧的噪音当成 73% 那一侧的信号。
要么分方向给门槛，要么承认做空侧的「顺风确认」本来就该更晚才算确认。

#### ④ 唯一过了留出集的维度是**量能**，不是标签

维度总账 §十一（留出段 5,296 根，主口径 `z_cluster`）里真正站住的几格：

| 格 | n | 命中 | 相对基准 | z_cluster |
|---|---:|---:|---:|---:|
| `无·贴线` + `vol_rel` 显著放量 | 448 | 16.3% | 2.5 倍 | **+5.89** |
| `无·贴线` + `vol_rel` 低于均量 | 941 | 2.0% | 0.31 倍 | **−8.61** |
| `无·真空` + `vol_rel` 显著放量 | 73 | 17.8% | 7 倍 | +3.47 |
| `无·真空` + `vol_rel` 低于均量 | 648 | 1.1% | — | −3.62 |

读法（机制讲得通）：**放量 = 有人在动，「不会走出单边」的判断容易失效；
缩量 = 安静成立。**

对出场的含义正好反过来用：**我们持仓需要一段行情发生，而缩量说明它不会来。**
这是全篇唯一一个「有机制 + 过了留出集」的信号。

## 3 · 明确不做的三件事

### 3.1 不做「连续 N 根没动作就平」

那是**时间闸的变体**。用户 2026-11-17 明确删过持仓时长闸（§25.3），
而且 `test_there_is_no_holding_time_gate` 用测试禁止 `max_hold_bars` 回来。

「持仓 N 根没动静就平」在语义上就是「时间到了」，只是把时钟换成了 K 线根数。
**要加必须先让用户重新授权，不能夹带。**

### 3.2 不调阈值凑信号

`逆风累计 N=2`、`恐慌盘` 的放量门槛 —— 全部是未验证初值，登记在册，
变更要留痕。这跟 D3（反转最小裕度）的纪律是同一条。

### 3.3 P0 保命分支里不读 K 线

硬不变量 #6：亏损到了就必须走，不许因为「K 线看着像洗盘」留仓。
所以第 1 道闸（止损）**排在 K 线判据之前**，不是并列。

## 4 · 架构：S5 必须是纯函数，kbar 作为「第二个 book」注入

现在 `run()` / `step()` 的签名里已经有一个注入的只读依赖：

```python
def run(thesis, bars, book: LineBook, ...)
```

S5 **不能**在 `thesis.py` 里直接查 `data/kbar.db` —— 那会让回放和增量两条路
各查一次，又变成「同一件事两个来源」。

正确形状：加一个和 `book` 平行的只读视图

```python
class KBarView:          # 或叫 WindBook
    def at(self, ts_ms) -> Optional[KBarFacts]   # label / side / vol_rel / event
```

- 回放：从库里一次性装载，按 ts 查。
- 增量：引擎每根 5m 从 kbar.db 读一行喂进去。
- `run()` 和 `step()` 依旧是**同一个函数**，只多一个入参。

这样「回放结果 = 实盘结果」由构造保证，不靠纪律。

## 6 · 怎么验证（不做拟合）

1. **逐闸归因**：在真实计划上跑，统计「每道闸各自改变了多少笔终态」。
   一条闸如果 0 次触发，那它在这一批样本上是装饰。
2. **只读敏感性表**：`逆风累计 N` 取 1/2/3，看是平台还是尖峰。**不挑格。**
3. **变异测试**：每道闸都要有能抓住它的变异体（删掉闸、方向判反、优先级错位）。
4. **不跑全链路回放**（用户明确「先别着急全链路回放」）——
   先逐闸归因，再谈整体。

## 8 · 第一版已实现 + 逐闸归因实测（2026-11-17）

### 8.1 已落地的三道闸

| 闸 | 默认 | 口径 | 终态 |
|---|---|---|---|
| 保本棘轮 | **开**（`s5_breakeven_r = 1.0`） | 浮盈 ≥1R → 止损移到「入场价 ± 往返成本」，只朝有利方向 | `CLOSED_BREAKEVEN`（**独立桶**） |
| 恐慌盘顺向 | **开**（`s5_panic_exit = True`） | `label=恐慌盘` 且 `side` 顺我；没 side 就不出场 | `CLOSED_TP` / `reason=panic_bar` |
| 缩量停滞 | **关**（`s5_stall_exit = False`） | `label ∈ (无·贴线, 无·真空)` 且 `vol_rel < 1.0` | `CLOSED_THESIS` / `reason=stall_exit` |

**为什么保本出场要独立一个 `CLOSED_BREAKEVEN`**：它既不是止损（没亏钱），
也不是止盈（没到 4R），也不是「预期被现实否决」（预期一度是对的，已赚到 1R）。
塞进任何一个已有桶都会静默改变那个桶的统计，而且没人会发现。

### 8.2 踩到并修掉的根内前视

第一版把「更新 best_fav」放在判定**之前**，于是同一根 K 可以：
用它的 `h` 造出保本价（+1.5R），再用它的 `l` 打到保本价 → 记「保本」。

**这是根内前视。** `OHLC` 分不出盘中先到哪个极值，
所以棘轮只能用**之前根**已经确立的 best_fav。修成「先判、后更新」，
`test_no_within_bar_lookahead` 钉住它。

顺带：`best_favorable_px` 必须跟着 `RunResult` 一起返回并落库 ——
增量推进每根调一次 `step()`，局部变量每根都重置 → 回放里棘轮能武装、
实盘里永远武装不了，而且两边都不报错。

### 8.3 逐闸归因（真实 11 条计划，240 根 5m 窗口）

| 变体 | 净 R | 终态分布 |
|---|---:|---|
| 基线（无 S5） | −2.43 | SL 2 / THESIS 3 / **FILLED 6** |
| +保本棘轮 | **−2.43** | **完全相同** |
| +恐慌盘 | −0.28 | TP 7 / THESIS 3 / FILLED 1 |
| 两者同开 | −0.28 | 同恐慌盘 |
| +缩量（实验） | **+0.36** | THESIS 8 / TP 3 |

三条如实结论：

**① 保本棘轮在这批样本上 0 次触发，是装饰。**
2 笔直接止损（没到过 +1R），6 笔窗口内还没走完，剩下的走了 4R 方向。
它保护的是「先赚 1R 再回吐」这类单子，而这批样本里**恰好一笔都没有**。
所以不是它错了，是**样本里没有它的用武之地** —— 不能因此说它有用，
也不能因此删掉它，要在更大的样本上再看。**它现在不该被当成已证实的改进。**

**② 恐慌盘有实质影响：净 R 从 −2.43 改善到 −0.28，改变 7 笔。**
方向与机制一致（末段一次性释放，拿到就走）。

**③ 缩量闸「最好看」（+0.36）恰恰是最危险的信号。**
它把 11 笔里的 8 笔变成 `CLOSED_THESIS` —— 几乎全平。
一个几乎平掉所有仓位的闸在任何样本上都会「改善」净 R，
因为它把亏损截断了、也把盈利截断了。**11 笔样本上的最优 = 过拟合的标准形状。**
所以它保持**默认关闭**，等条件化之后的 lift（对基准 26.8% / 31.4%）量出来再议。

⚠ **样本量必须写在结论旁边**：11 笔、单一时段、6 笔还没走完。
上面任何一个数字都不构成统计证据，只构成「这道闸会不会响」的工程事实。


### 7.1 分批还是一把全平？

### 7.3 「缩量未兑现」要不要授权？

它读的是**量能状态**（有机制、过留出集），不是根数。
但落地时不可避免要「连续几根缩量」才算数 —— 那一步就是时间闸的形状。
用户 2026-11-17 明确删过持仓时长闸，并用测试禁止它回来，所以**必须显式授权**，
不能夹带。替代写法：不数根数，只看**当前这根**是否「缩量 + 贴线」，
命中即出场（无累计，纯状态）。这样不碰时间闸，但会非常频繁地触发。

### 7.4 做空侧的确认要不要更严？

同一门槛套两个方向会把噪音当信号 —— 分方向给门槛，还是统一门槛但接受做空侧更差？
