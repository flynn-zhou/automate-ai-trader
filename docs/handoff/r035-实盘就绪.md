## 六点三五、实盘模式已就绪（等注资即可切）

`AI_TRADE_MODE=live` 的完整链路已经写好并测试，**唯一缺的是账户资金**（现 0.53U）。

### 三条不可妥协的实盘保护

1. **verify-first**：下单后不信任返回值，立刻查 `/fapi/v2/positionRisk` 核对真实持仓；
   对不上就立刻反向平掉 + 熔断，之后拒绝一切新单。
   测过的场景：交易所返回成功但仓位没动（静默失败）必须被抓住 —— `tests/test_live_safety.py` 钉死。
2. **启动对账**：`engine.reconcile_live()` 以交易所持仓为唯一真相，
   数据库与交易所不一致时按交易所修正并告警。数据库只是记账，钱在交易所。
3. **失败要快**：live 模式缺 `AI_API_KEY/AI_API_SECRET` 时在任何 I/O 之前 `SystemExit`，
   绝不"降级成纸面偷偷跑"—— 那样最危险，你以为在下真单，其实在记账。

### 切换步骤（用户注资后）

```bash
# 1) 写入凭证（不落配置文件，只进 /etc/ai-trader/env）
echo 'AI_TRADE_MODE=live'   >> /etc/ai-trader/env
echo 'AI_API_KEY=...'       >> /etc/ai-trader/env
echo 'AI_API_SECRET=...'    >> /etc/ai-trader/env
# 2) 停掉老系统，避免两个程序抢同一个账户下单
systemctl stop cryptobot && systemctl disable cryptobot
# 3) 起新系统
systemctl restart ai-trader && journalctl -u ai-trader -f
```
