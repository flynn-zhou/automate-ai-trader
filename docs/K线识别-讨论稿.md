## 一、先说最大的风险

「K 线的意图与目的」是**心理归因**，不是可观测量。没有人能给一根 K 线标注
「它的意图是诱多」—— 标注者自己也是事后解释。

如果直接去实现一个「意图分类器」，会得到一个**无法验证**的东西：
它总能给每个形态配一个说法，而说法对不对永远说不清。这正是本项目
一直禁止的「看图说话」。

**出路：把「意图」换成可测的替代问题。**

| 想说 | 换成可测的 |
|---|---|
| 这根 K 想干什么 | 这根 K 之后 N 根的方向分布是否偏离无条件基线 |
| 是诱多还是真突破 | 突破后是否被推回（回撤概率），以及推回的速度 |
| 恐慌盘清空了吗 | 是否探穿前极值后收回区间内（假破的可判据） |
| 带不带量 | 相对中位量的倍数（必须相对化，绝对量随牛熊漂移） |

一句话：**不判断意图，只判断这根 K 对后续分布的预测力。**
预测力可以样本外检验，意图不能。

## 二、我们真正的优势：3s 逐笔，不是 1h K

看 1h K 线的人只有 4 个数（开高低收）+ 1 个量。
**我们本地有 187992 根 3s 桶，且每笔带主动买卖方向（`is_buy`）。**

这意味着同一根 1h K，别人看到一根长下影，我们能看到它的长下影是：

- 一根 3s 桶瞬间砸下去的（流动性真空，恐慌）
- 还是慢慢阴跌 40 分钟然后拉回（承接，吸收）
- 主动卖量大还是主动买量大（谁在推）

**这两种内部路径在 1h 上完全同形，但含义相反。** 这是我们唯一的结构性优势，
任何设计都应该把它用上，否则等于放弃自己的长处去和别人比看图。

## 三、三层结构

### 第一层：事实（可测量，无判断）

| 量 | 怎么算 |
|---|---|
| OHLCV | 这根 K 本身 |
| 位置 | 在 v11 四线（S/R/P/K）哪两条之间、距最近线多少 % |
| 段内序号 | 当前 #fam.seg 里的第几根 |
| 内部路径 | 这根 1h 由 1200 个 3s 桶组成：先跌后涨？单边？V 形？ |
| 主动买卖比 | sum(qty where is_buy) / sum(qty)，真实买卖压力 |
| 量能 | 相对 N 根中位量 / 相对同时段中位量 |

### 第二层：读数（把事实压成少数正交维度）

我提议六个，每个都可算、互相不重复：

| 维度 | 算什么 | 为什么单独拿出来 |
|---|---|---|
| **位置** | 距关键价 %、是否贴线、段内第几根 | 同一个形态在高位和低位含义相反 |
| **形状** | 实体占比、收盘位置、上下影对称性 | 谁在防守的直接证据 |
| **量能** | 相对量倍数、量价背离 | 「带不带量」 |
| **内部路径** | 3s 走势形态、最大单桶占比 | 区分恐慌砸盘 vs 阴跌承接 |
| **吸收** | 大量但价格不动 / 穿透但不回 | 区分真破与假破 |
| **主动方向** | taker 买卖比、大单方向 | 谁在主动成交 |

### 第三层：预测（唯一可证伪的部分）

每种读数组合 → 未来 N 根的收益分布，**对着无条件基线比**。

必须同时报：单笔均值 / t 值 / 逐年 / 样本外 / **beta 剥离后的 alpha**。

这一层是本项目唯一认的产出。前两层只是特征工程。

## 四、用户提的三点，逐个具体化

### 4.1 意图与目的

不可直接标。转成三个可测的替代问题：

1. 这根 K 之后，价格有没有被「推回它来的方向」？回撤概率 vs 基线
2. 后续 N 根的方向分布是否偏斜？偏多少、显著吗
3. 若在此入场，最坏情况（MAE）中位数是多少

### 4.2 是否恐慌盘

这个词至少对应**三个不同事件**，判据完全不同，必须先分清是哪个：

**A. 恐慌抛售**

    单根跌幅 > k x sigma      （k 不拍脑袋，用分位数定）
    量 > m x 中位量
    随后 N 根回收 > x%

**B. 恐慌被清空（洗盘完成 / 假破）**

    盘中探穿前一个极值（新低或新高）
    伴随量峰
    但【收盘】回到原区间内        <-- 这一条是关键，可判

**C. 空头恐慌平仓（挤空）**

    单根涨幅 > k x sigma
    量峰
    主动买占比显著 > 0.5
    资金费率 / 持仓量骤降（若能取到）

三个都是**可数的判据**，不需要「看图」。分不清这三个，就没法定义「恐慌盘」。

### 4.3 带不带量

绝对量没用（牛熊漂移、BTC 成交量长期趋势）。必须相对化：

| 指标 | 算法 |
|---|---|
| 相对量 | 这根量 / 前 N 根中位量 |
| 时段相对 | 这根量 / 同小时的历史中位量（日内效应很强） |
| 主动占比 | taker buy / 总量 |
| 集中度 | 最大单根 3s 桶量 / 这根总量 |

集中度这个指标大多数人没有 —— 我们有 3s 数据，能算出「量是均匀的还是集中在某一瞬间」。
这才是「带量」的真含义：**一根 3s 桶砸出 40% 的量，和 40 分钟均匀放量，不是一回事。**

## 五、我认为还该有、但用户没列的

1. **位置的前置性。** 同一个形态在关键价上和在半空中，含义完全相反。
   位置必须作为**条件**参与，不是特征之一。直接和 v11 四线绑定。
2. **时间维度。** 贴着关键价磨了 6 根才破，和一次砸穿，含义相反。
   要有「第几根在试探」这个量。
3. **后续确认窗口。** 单根 K 无法自我确认，必须定义「看几根之后算确认」。
   这个窗口长度本身是个要定的参数。
4. **失败样本专库。** 每条规则都要存下它出错的那些案例。
   只统计成功率不分析失败样本，是本项目已经踩过的坑。

## 六、必须回答的五个问题（没答完不要写代码）

1. **「恐慌盘」指哪个？** 上文 4.2 的 A / B / C，还是别的？
2. **周期用哪个？** 1h（与区间演化同周期，好对齐）还是 15m/5m（3s 优势更明显）？
3. **输出什么形式？** 打分（连续）/ 是·否（二值）/ 多档（强中弱）？
4. **辅助哪个动作？** 进场时机 / 离场预警 / 两者都要？两者的判据不一样。
5. **怎么算「识别对了」？** 这是最重要的一条 —— 没有它，整个能力无法验收。

## 七、落地顺序（讨论定稿后）

    1. 先只做【事实层】。把每根 K 的内部路径、主动买卖比、集中度算出来落库。
       这一步不涉及任何判断，纯粹是可复现的数值。
    2. 在事实层上做【描述统计】：先看这些量与后续收益到底有没有关系。
       大概率是「几乎没有」—— 这才是诚实的起点。
    3. 有关系的那几个，才值得进【预测层】做样本外检验。
    4. 全部用不上，就承认这条路不通，回去想别的。

**不要跳过第 2 步直接建分类器。** 那是本项目反复禁止的「把线索当策略」。
