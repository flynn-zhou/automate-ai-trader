## 六点三、策略已推翻重建（2026-11-01）

**当前策略 = 4h SMA200 只做多趋势跟随**（`AI_STRATEGY=trend`），3s 剥头皮保留为对照（`scalp`）。

### 为什么推翻

用一年期数据把信号家族逐个证伪，结论写在 `ai_trader/trading/trend.py` 顶部的注释里：

| 方向 | 检验 | 结论 |
|---|---|---|
| 1m 微型动量（原策略） | 7591 个信号未来收益 | 15-120 分钟 t = -2.2~-2.9，**显著为负**，幅度 0.02% << 成本 0.11% |
| 反向（均值回归） | 样本外 | t=0.15 不显著，去掉最优 5% 后转负 = 靠极端事件，不是边际 |
| 趋势跟踪 5m-4h | 64 组参数 | 仅 5 组净正，最好的 27 笔 = 样本不足 |
| 日线双向趋势 | 48 组，训练/测试各半 | **0 组两段同为正**，测试段 t 低至 -5 |
| **只做多 + 4h SMA200** | 六年，样本外 | **+666% vs 买入持有 +503%，回撤 30-47% vs 77%，卡玛 14-22 vs 6.5** |

### 核心洞察（写在代码里防止以后忘）

费用按**名义**收，而名义 = 风险 / 止损百分比。所以止损越宽，费用占风险的比例越小：

- 止损 0.40% → 往返费吃掉 **27.5%** 风险预算，盈亏平衡胜率要 **49%**
- 止损 25% → 费用只占 **2%**，趋势策略吃到大波段就能覆盖

加上频率从「每天几十次」降到「每两周一次」，成本结构彻底变了。这正好绕开杀死 k-trader 的那个结构。

### 一致性保证

`tools/verify_trend.py` 会把线上 `TrendStrategy` 和回测口径逐笔比对，必须输出「逐笔一致：是」（181 笔、+665.9%）。**改动策略后先跑这个再上线。**

### 已实现

- `ai_trader/trading/trend.py` — 策略本体；SMA **不含被判定的那根**（与回测 `sma_at` 一致）
- `engine._step_trend()` — 独立分支，每根 4h 收盘才判断；3s 心跳只喂 K 线 + 盯熔断止损
- `tools/cutover_trend.py` — 切换时平旧仓 + 对齐 `executor_state`（幂等）
- 熔断止损 25%（正常靠 SMA 交叉平仓）；止损出局后同一根 4h 内禁止再进场（防死循环）
- 单元测试 `tests/test_trend.py`（5 个），合计 28 个全绿

### 已知风险（必须对用户说清）

这是**多头 beta + 趋势过滤**，不是市场中性：BTC 长期不走趋势时会亏（2022 年 -20%）；不做空，下跌市里是空仓等待而不是赚钱；1.5x 杠杆历史最大回撤 58%。
